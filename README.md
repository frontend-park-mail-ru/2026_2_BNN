# 2026_2_BNN
Frontend-репозиторий команды BNN. Реализуем BNN во всей красе и функциональности!📔

## Что такое BNN

BNN - это платформа для заметок и организации работы: в ней можно вести личные и командные заметки, документы, задачи и базы данных в одном месте.

## Структура проекта

| Путь | Что хранится |
| --- | --- |
| `pages/` | HTML-страницы проекта (`login.html`, `register.html`) |
| `styles/` | Стили проекта (`styles.css`) |
| `assets/images/` | Фоновые изображения и графика интерфейса |
| `assets/icons/` | Иконки и логотипы |
