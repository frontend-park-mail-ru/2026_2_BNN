# Профиль

`src/pages/profile.ts` собирает диалог и формы, подписывается на Store и управляет
анимацией открытия/закрытия. Обработчики вызывают actions; отображение операций
обновляется через подписку, без замены HTML всей формы.

- `password-form.ts` — проверка полей и отправка смены пароля.
- `two-factor-form.ts` — ввод кода, показ QR и состояние кнопок 2FA.
- `avatar-form.ts` — выбор файла, подготовка и отправка кадрированного аватара.
- `avatar-crop.ts` — работа с canvas и кадрированием.
- `form-view.ts`, `view.ts`, `date.ts` — ошибки полей и отображение профиля.

`src/flux/profile/` содержит actions, типы событий и ProfileStore. Store хранит
открытое представление, состояние и ошибки операций, адрес текущего QR. Пользователь
хранится только в AuthStore: событие `profile/user-updated` обновляет все данные
после загрузки, а после мутаций — только аватар или настройку 2FA.

Контекст формы позволяет отличать завершение её запроса от ответа для уже закрытого
представления. Мутации не отправляются повторно, пока идёт такой же запрос.
Ответ старой сессии не меняет Store. Actions освобождают QR при закрытии и при
запоздавшем ответе; генерации QR выполняются последовательно, поскольку сервер
заменяет секрет при каждой генерации.
