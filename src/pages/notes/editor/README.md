# Редактор заметки

`notes.ts` собирает страницу, список, поиск и диалоги. Экземпляр редактора создаётся
на время открытия одной заметки через `createNoteEditor`.

- `controller.ts` — подключение событий, ввод, клавиатура, голосовой ввод и жизненный цикл.
- `document.ts` — чтение заголовка и блоков из DOM, подготовка снимка для сохранения,
  применение серверных идентификаторов без замены текущего текста.
- `selection.ts`, `caret.ts`, `inline-format.ts` — выделение, каретка и форматирование.
- `block-menu.ts`, `block-view.ts` — меню типов блоков и данные их шаблонов.
- `attachment-input.ts` — вставка, загрузка и удаление вложений в редакторе.
- `persistence.ts` — связь снимка редактора с `noteActions`.
- `autosave.ts` — задержка, последовательная очередь, повторная попытка и `flush`.
  Не зависит от Store, API и разметки.
- `constants.ts` — общие настройки редактора и подписи интерфейса.

Сетевые запросы выполняются в `src/flux/notes/note-actions.ts`. Успешные результаты
попадают через Dispatcher в NotesStore. Подписки отдельно обновляют список и подпись
сохранения; ответ сервера не заменяет текст, который пользователь продолжает вводить.

Перед переходом роутер вызывает `beforeLeave()`: редактор останавливает голосовой ввод,
дожидается вложений и досылает очередь. При ошибке переход отменяется, DOM и очередь
остаются для повторной попытки. После успешного перехода `destroy()` снимает события,
подписки и таймеры. При завершении сессии запоздавшие ответы отбрасываются в actions.
