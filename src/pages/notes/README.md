# Страница заметок

`src/pages/notes.ts` собирает модули, связывает навигацию и диалоги удаления/выхода,
подключает жизненный цикл страницы. После загрузки редактора обновления списка
и поиска не заменяют его DOM.

- `elements.ts` — поиск узлов страницы.
- `view.ts` — данные шаблонов из состояния Store.
- `selectors.ts` — чтение заметок, тегов и фильтра.
- `list.ts` — список заметок, фильтр тегов, подписки и точечное обновление заголовка.
- `search.ts` — чистые функции поиска; `search-controller.ts` — события, задержка,
  догрузка содержимого и обновление результатов.
- `tag-picker.ts` — выбор тегов открытой заметки и создание тега из меню.
- `tags-dialog.ts` — управление общим справочником тегов.
- `editor/` — ввод, форматирование, вложения и автосохранение.
- `voice-input/` — распознавание речи и вставка текста.

Загрузка списка, отдельной заметки и фоновых деталей выполняется в
`src/flux/notes/note-actions.ts`. Actions объединяют одинаковые запросы,
ограничивают параллельную догрузку и отбрасывают ответы старой сессии.
NotesStore хранит данные, ошибку списка, состояние загрузки каждого id и статус
фоновой догрузки. Страница и модули подписываются на Store; они не записывают
результаты запросов обратно в него.

`npm run test:notes` проверяет загрузку, гонки запросов, поиск и фильтрацию.
`npm run test:editor` проверяет сохранение и переходы между страницами.
